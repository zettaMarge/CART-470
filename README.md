### Home Work
While the disappearing navbar was easy enough to code & style as a component with a single given behaviour, it gets more complicated when that behaviour needs to change based on a separate component's state. Thankfully React provides a simple solution to this with Contexts, although it will still require some rework of the component I've made so far to work as intended. There are also some complications with it related to typescript causing errors when creating a new context without a default value or when setting this default to null, but I found a way to circumvent that.
